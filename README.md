# 收工喵（Windows 桌面宠物 · 双版本架构）

一只会说话、会跟着鼠标跑、会按时提醒你的橘猫桌宠，常驻在桌面上陪你。
项目采用 **core.py 公共核心 + 双 UI 入口** 架构：`main.py`（tkinter 零依赖版）与 `main_qt.py`（PyQt5 精美版）共用同一套核心逻辑，**数据互通、单实例互斥（两个版本不能同时开）**。

## 双版本怎么选

| | `main.py`（tkinter 版） | `main_qt.py`（PyQt5 版） |
|---|---|---|
| 依赖 | **零第三方依赖**，装 Python 就能跑 | 需 `pip install PyQt5` |
| UI | 简洁实用 | **更精美**（暖橙圆角对话框 + QSS 样式菜单/托盘） |
| 动画 | 流畅（Canvas 帧动画） | **更流畅**（原生帧 + 缩放三级缓存，无卡顿） |
| 托盘 | ctypes 自绘托盘 | QSystemTrayIcon 原生托盘 |
| 打包 | `build_tk.bat` → `doubao-pet-tk.exe` | `build_qt.bat` → `doubao-pet-qt.exe` |
| 数据 | 共用 `%APPDATA%\DoubaoPet\pet_data.json` | 共用同一份，切换版本设置不丢 |

## 功能

| 操作 | 效果 |
|---|---|
| 左键按住拖动 | 把桌宠拖到任意位置 |
| 单击 | 惊讶 / 开心反应 + 气泡 |
| 双击 | 开心跳跃 + 气泡 |
| 右键 | 菜单：**选择形象**、切换状态、**定时提醒**、**每日提醒**、**大小调节**、跟随鼠标、**定时睡觉**、开机自启、退出 |
| 待机时 | 安静站在原地，随机冒泡说话 |
| **跟随鼠标** | 开启后桌宠追着光标跑：**距离近→走路动画、匀速跟随**；**距离远→快速跑动画、快速靠近**；贴得很近就停住（右键菜单开关） |
| **定时提醒** | 自定义时间与内容，到点小猫**自动跑到屏幕中间**，猫头方向弹出**微信式气泡**显示内容 + 提示音；支持**分钟轮询**（每 N 分钟提醒一次）；重启后提醒保留 |
| **每日提醒** | 设置固定时刻（如 08:30）：**每天**这个时间自动提醒，像闹钟一样，可多条、可取消；可勾选"**到点后自动睡眠**"（可选 锁屏/睡眠/关机，倒计时秒数可自定义，默认 10 秒，带取消按钮） |
| **定时睡觉** | 设置睡觉时间：到点小猫自动入睡，点击一下叫醒 |
| **大小调节** | 增大 / 减小（步长 50px），范围 **150px ~ 600px**，或直接选预设尺寸 |
| **选择形象** | 5 种形象：**黄色小猫 / 小熊猫 / 大熊猫 / 卡皮巴拉 / 哈士奇**，选择后记忆，重启保持 |
| **开机自启** | 勾选后下次开机自动运行桌宠（无控制台窗口） |

五种状态：**待机 / 开心 / 睡觉 / 惊讶 / 移动**，五种形象切换即时生效。

### 动画

- **跟随鼠标分档**：开启"跟随鼠标"后——
  - 鼠标离得**远**（>260px）：宠物**快速跑动画**，快速靠近鼠标，**面朝鼠标方向**
  - 鼠标离得**近**（<180px）：宠物**走路动画**，匀速跟随，**面朝鼠标方向**
  - 两个档位之间有 **±40px 滞回带**（180~260px 内保持当前档位），临界距离附近不会跑/走快速闪动
  - 贴得**很近**（≤26px）或**鼠标在宠物窗体内**：停住待机（方便右键点菜单，不会追过来盖住）
  - 静止档带**脱离滞回**：一旦停住，需**离开窗口且距离超过 86px** 才恢复动画——临界点来回移动不闪动
  - 所有动画帧统一画布尺寸（640×600）、**头部朝向统一朝右**（朝左时自动镜像），切换时不会忽大忽小、不会左右乱转、不会显示不全
- **待机静止**：待机时安静停在原地（不飘动不摇摆）
- **开心跳跃**：单击 / 双击 / 提醒触发时跳起来，头顶飘出**爱心 / 星星 / 小花**，1 秒多后消散
- **睡觉打呼**：睡觉时静止，头顶每隔一会儿飘出灰色 **zZz**
- **提醒跑动**：提醒到点，宠物从当前位置用跑步动画跑到屏幕中心弹气泡，完成后**自动跑回原位**

### 开机自启

- 右键桌宠 → 勾选 **开机自启**，写入当前用户的注册表启动项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的"收工喵"值），**无需管理员权限**
- 自启用 `pythonw.exe`（源码运行）或 exe 本身启动，登录系统后自动出现在桌面，没有黑色控制台窗口
- 取消勾选即可关闭；也可在任务管理器"启动应用"里禁用
- **注意**：移动了项目目录 / exe 位置后，先取消再重新勾选一次，让启动路径更新

### 提醒持久化

- 定时提醒、每日提醒、形象、大小、位置全部保存在 **`%APPDATA%\DoubaoPet\pet_data.json`**（Windows 标准用户数据目录），**重启桌宠、重启电脑、换用另一版本都不会丢**
- 启动恢复时会冒泡提示"已恢复 N 条提醒、M 条每日提醒"
- 已过期的一次性提醒不会恢复（不会开机补弹一堆过期弹窗），取消提醒同步更新文件
- 首次运行若检测到旧版（exe 旁 / 源码目录）的 `pet_data.json`，会自动迁移到 `%APPDATA%`

### 每日提醒（闹钟）

- 右键 → **每日提醒** → 设置每日提醒：输入**时刻**（如 08:30）和内容，**每天这个时间**宠物自动**跑到屏幕中间**，猫头方向弹出**微信式气泡**显示内容 + 提示音，约 8 秒后宠物跑回原位置
- 可同时设置多条不同时间的每日提醒
- **到点动作**：设置时可选择"**无 / 锁屏 / 睡眠 / 关机**"并填**倒计时秒数**（默认 10 秒，可改 1~300）——到点弹气泡 + 秒数倒计时 + **取消按钮**；倒计时结束还没点取消，Windows 自动执行所选动作
- 同一天同一时间只提醒一次（重启也不重复弹），第二天照常提醒
- 菜单里列出每条提醒（含时间），随时可取消

### 定时提醒（支持轮询）

- 右键 → **定时提醒** → 添加提醒：输入**分钟数**（如 `30`，可勾选"**开启轮询**"，之后每 30 分钟提醒一次）或**时刻**（如 `14:30`，单次提醒）
- 开启轮询的提醒会**记忆**，重启后继续周期提醒；未开启轮询的只生效一次
- 到点：宠物跑向屏幕中心弹微信式气泡 + 提示音，普通提醒 8 秒后消失并跑回原位

### 定时睡觉

- 右键 → **定时睡觉** → 设置睡觉时间：输入**分钟数**或**时刻**（今天已过顺延明天）
- 到点后宠物自动进入睡觉状态，直到**点击一下**（或右键菜单）才会醒来
- 设置后菜单显示"取消睡觉计划（剩 X 分）"，随时可取消

### 睡眠 / 休眠恢复

- 电脑睡眠或休眠后唤醒，Windows 有时会让透明置顶窗口"消失"
- 桌宠内置**看门狗**：每 2.5 秒自检一次，检测到系统刚从睡眠恢复时，自动重新应用透明与置顶、强制重绘、夹回屏幕内，并冒泡"我回来啦～"
- 无需任何操作，唤醒电脑后桌宠自动回到桌面

### 大小调节

- 范围 **150px ~ 600px**（最小/最大阈值，600px 为素材原始分辨率上限）
- 右键 → **大小** → 增大 / 减小（每次 ±50），或直接点选预设尺寸
- 调整时以窗口底部中心为锚点，位置保持稳定；缩放即时完成
- **尺寸与位置都保存**：退出后重启（或重启电脑）保持上次的大小和位置（自动夹回屏幕内）

## 快速开始

### 方式一：源码运行（tk 版，零依赖）

1. 安装 Python 3（<https://www.python.org/downloads/>，安装时勾选 **Add Python to PATH**）
2. 双击 **`run.bat`**（或命令行执行 `python main.py`）

### 方式二：源码运行（PyQt5 版）

```bat
pip install PyQt5 -i https://pypi.tuna.tsinghua.edu.cn/simple
python main_qt.py
```

### 方式三：直接跑打包好的 exe

双击 `dist_nuitka\doubao-pet-tk.exe` 或 `dist_nuitka\doubao-pet-qt.exe`，无需装 Python。

## 打包成 exe

项目提供两个打包脚本（需 VS 2022 MSVC + pip 安装 Nuitka）：

| 脚本 | 产物 | 说明 |
|---|---|---|
| `build_tk.bat` | `dist_nuitka\doubao-pet-tk.exe` | tkinter 版，体积小（约 28MB） |
| `build_qt.bat` | `dist_nuitka\doubao-pet-qt.exe` | PyQt5 版，体积更大（含 Qt 运行库） |

**Nuitka 编译版把 Python 代码真正编译成原生 C 再链接为 exe，行为更接近普通程序，比 PyInstaller 抗杀软误报。**

```bat
REM 编译环境准备（一次性）
pip install nuitka -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install PyQt5 -i https://pypi.tuna.tsinghua.edu.cn/simple   REM 仅 qt 版需要

REM 然后双击 build_tk.bat 或 build_qt.bat
```

**注意**：
- 本机 Python 是定制版（tcl/tk 库在虚拟文件系统），tk 版编译需手动指定 `--tcl-library-dir` / `--tk-library-dir`（见 `build_tk.bat`）；普通完整安装的 Python 不需要
- 数据文件在 **`%APPDATA%\DoubaoPet\pet_data.json`**，与 exe 位置无关——换机器/换目录都不丢设置，**外发时只发一个 exe 即可**
- 开机自启如果用 exe：先取消再重新勾选一次，让注册表指向 exe

## 目录结构

```
desktop-pet/
├── core.py                 # 公共核心（路径/数据/解析/调度/自启/单实例/DPI，双版本共用）
├── main.py                 # tkinter 版主程序（零第三方依赖）
├── main_qt.py              # PyQt5 版主程序（UI 精美、动画流畅）
├── build_tk.bat            # tk 版 Nuitka 打包脚本
├── build_qt.bat            # PyQt5 版 Nuitka 打包脚本
├── run.bat                 # 一键启动脚本（tk 版）
├── requirements.txt        # 依赖说明
├── sprites/                # 精灵素材（透明 PNG，600×600，朝右为基准）
│   ├── idle.png            #   待机（及各状态帧）
│   ├── run1.png~run4.png   #   跑步帧（跟随快跑）
│   ├── walk1.png~walk4.png #   走路帧（慢速跟随）
│   ├── redpanda/           #   小熊猫形象（20 帧）
│   ├── panda/              #   大熊猫形象（20 帧）
│   ├── capybara/           #   卡皮巴拉形象（20 帧）
│   └── husky/              #   哈士奇形象（20 帧）
└── dist_nuitka/            # Nuitka 编译产物目录
    ├── doubao-pet-tk.exe   #   tk 版单文件 exe
    └── doubao-pet-qt.exe   #   PyQt5 版单文件 exe
```

> 提示：按住桌宠拖动时浮动动画会暂停，松手后自动恢复；**所有状态都会自动回到默认待机**——开心/惊讶等短暂状态 1~2 秒后自动恢复，睡觉状态默认 3 分钟后自动醒来（气泡提示"睡醒啦～"），单击也可立即唤醒。
